⌘Z undoes a dashboard edit, and ⇧⌘Z redoes it. A drag, a resize, a tile's Save and a
delete are each one step, so one keystroke undoes one act. The stack is session-only —
a reload starts clean, and the dashboard's saved versions remain the durable record.
A keystroke inside a text field, or while a dialog is open, is left to the browser.
