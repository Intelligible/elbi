Dashboards can be exported as a shareable page. `elbi snapshot <dashboard>`, or **Export →
Shareable page** on the dashboard, writes one self-contained, read-only HTML file: every page
of the published dashboard with its current values, sortable tables, charts with tooltips,
and the derivation and data version behind each figure. It carries no version history and
needs no access to the app. Each data widget can also download its rows as CSV.
