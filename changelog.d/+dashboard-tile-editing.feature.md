A dashboard's tiles can be edited from the dashboard itself. Each tile carries a menu
with **Edit…** and **Delete**: the editor changes a tile's title, a text tile's
markdown, and which derivation a bound tile reads, warning before you save a name
nothing provides; deleting asks first and says what it does and does not remove.
Dragging and resizing already persisted — the resize handle appears on hover in a
tile's bottom-right corner — so laying a dashboard out no longer means editing the
spec JSON. `viz`, params and interactions still live there.
